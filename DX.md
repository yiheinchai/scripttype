# Is ScriptType actually easier to read?

The project only earns its keep if the ScriptType form is easier to write and reason
about than the type-level original. That is a claim about readability, so it is put
side by side here rather than asserted. Every pair below is generated by the
decompiler and verified to recompile to a type identical to the original.

Regenerate with `npx tsx src/dx-report.ts`.

## What actually gets easier

**Control flow becomes linear.** A conditional type nests: each `? :` buries the next
case one level deeper, so understanding the last branch means holding all the earlier
ones in your head. Statements with early `return` put the cases side by side instead.

**Loops stop being recursion.** A tail-recursive alias with an accumulator parameter
is a `while` loop that has been hand-converted, including the manual threading of the
accumulator through every call. Recovering the loop removes that bookkeeping.

**Intermediate values get names.** `const` gives a name to a subexpression; a
conditional type has to either repeat it or introduce an `extends infer` binding whose
purpose is invisible.

**What does not get easier.** Patterns are still patterns: `matches<...>` with
`Hole<'N'>` is a little more verbose than `extends ... infer N`. Where the original is
already a one-liner, ScriptType is longer and there is nothing to gain — the last
example below is deliberately one of those.

## __Split

`01-type-level-programming/ts-toolbelt/sources/String/Split.ts`

A loop written as recursion. Recovery restores the loop.

**Original TypeScript** (4 lines)

```ts
export type __Split<S extends string, D extends string, T extends string[] = []> =
    S extends `${infer BS}${D}${infer AS}`
    ? __Split<AS, D, [...T, BS]>
    : [...T, S]
```

**ScriptType** (13 lines)

```ts
export function __Split(S: string, D: string) {
  let T: any[] = []
  let s = S
  while (true) {
    const m1 = matches<`${Hole<"BS">}${typeof D}${Hole<"AS">}`>(s)
    if (!m1) {
      break
    }
    s = m1.AS
    T.push(m1.BS)
  }
  return [...T, s]
}
```

**Compiles back to**

```ts
export type __Split<S extends string, D extends string> = __Split__loop<S, [], D>
type __Split__loop<S extends string, T extends any[], D extends string> =
  S extends `${infer BS}${D}${infer AS}` ? __Split__loop<AS, [...T, BS], D> : [...T, S]
```

## Iterator

`01-type-level-programming/ts-pattern/src/types/helpers.ts`

Loop-until-condition: recursion in the false branch.

**Original TypeScript** (4 lines)

```ts
export type Iterator<
  n extends number,
  it extends any[] = []
> = it['length'] extends n ? it : Iterator<n, [any, ...it]>;
```

**ScriptType** (10 lines)

```ts
export function Iterator(n: number) {
  let it: any[] = []
  while (true) {
    if (matches<typeof n>(it['length'])) {
      break
    }
    it.unshift(any)
  }
  return it
}
```

**Compiles back to**

```ts
export type Iterator<n extends number> = Iterator__loop<[], n>
type Iterator__loop<It extends any[], N extends number> =
  It['length'] extends N ? It : Iterator__loop<[any, ...It], N>
```

## ExtractTypeFromStringSelectExpression

`04-query-builders-orm/kysely/src/parser/select-parser.ts`

Six-deep nested conditionals become flat early returns.

**Original TypeScript** (35 lines)

```ts
export type ExtractTypeFromStringSelectExpression<
  DB,
  TB extends keyof DB,
  SE extends string,
> = SE extends `${infer SC}.${infer T}.${infer C} as ${string}`
  ? `${SC}.${T}` extends TB
    ? C extends keyof DB[`${SC}.${T}`]
      ? DB[`${SC}.${T}`][C]
      : never
    : never
  : SE extends `${infer T}.${infer C} as ${string}`
    ? T extends TB
      ? C extends keyof DB[T]
        ? DB[T][C]
        : never
      : never
    : SE extends `${infer C} as ${string}`
      ? C extends AnyColumn<DB, TB>
        ? ExtractColumnType<DB, TB, C>
        : never
      : SE extends `${infer SC}.${infer T}.${infer C}`
        ? `${SC}.${T}` extends TB
          ? C extends keyof DB[`${SC}.${T}`]
            ? DB[`${SC}.${T}`][C]
            : never
          : never
        : SE extends `${infer T}.${infer C}`
          ? T extends TB
            ? C extends keyof DB[T]
              ? DB[T][C]
              : never
            : never
          : SE extends AnyColumn<DB, TB>
            ? ExtractColumnType<DB, TB, SE>
            : never
```

**ScriptType** (53 lines)

```ts
export function ExtractTypeFromStringSelectExpression(DB, TB: keyof typeof DB, SE: string) {
  const m1 = matches<`${Hole<"SC">}.${Hole<"T">}.${Hole<"C">} as ${string}`>(SE)
  if (m1) {
    if (matches<typeof TB>(`${m1.SC}.${m1.T}`)) {
      if (m1.C in DB[`${m1.SC}.${m1.T}`]) {
        return DB[`${m1.SC}.${m1.T}`][m1.C]
      }
      return never
    }
    return never
  }
  const m2 = matches<`${Hole<"T">}.${Hole<"C">} as ${string}`>(SE)
  if (m2) {
    if (matches<typeof TB>(m2.T)) {
      if (m2.C in DB[m2.T]) {
        return DB[m2.T][m2.C]
      }
      return never
    }
    return never
  }
  const m3 = matches<`${Hole<"C">} as ${string}`>(SE)
  if (m3) {
    if (matches<AnyColumn<typeof DB, typeof TB>>(m3.C)) {
      return ExtractColumnType(DB, TB, m3.C)
    }
    return never
  }
  const m4 = matches<`${Hole<"SC">}.${Hole<"T">}.${Hole<"C">}`>(SE)
  if (m4) {
    if (matches<typeof TB>(`${m4.SC}.${m4.T}`)) {
      if (m4.C in DB[`${m4.SC}.${m4.T}`]) {
        return DB[`${m4.SC}.${m4.T}`][m4.C]
      }
      return never
    }
    return never
  }
  const m5 = matches<`${Hole<"T">}.${Hole<"C">}`>(SE)
  if (m5) {
    if (matches<typeof TB>(m5.T)) {
      if (m5.C in DB[m5.T]) {
        return DB[m5.T][m5.C]
      }
      return never
    }
    return never
  }
  if (matches<AnyColumn<typeof DB, typeof TB>>(SE)) {
    return ExtractColumnType(DB, TB, SE)
  }
  return never
}
```

**Compiles back to**

```ts
export type ExtractTypeFromStringSelectExpression<DB, TB extends keyof DB, SE extends string> =
  SE extends `${infer SC}.${infer T}.${infer C} as ${string}`
    ? `${SC}.${T}` extends TB
      ? C extends keyof DB[`${SC}.${T}`] ? DB[`${SC}.${T}`][C] : never
      : never
  : SE extends `${infer T}.${infer C} as ${string}`
    ? T extends TB ? C extends keyof DB[T] ? DB[T][C] : never : never
  : SE extends `${infer C} as ${string}`
    ? C extends AnyColumn<DB, TB> ? ExtractColumnType<DB, TB, C> : never
  : SE extends `${infer SC}.${infer T}.${infer C}`
    ? `${SC}.${T}` extends TB
      ? C extends keyof DB[`${SC}.${T}`] ? DB[`${SC}.${T}`][C] : never
      : never
  : SE extends `${infer T}.${infer C}`
    ? T extends TB ? C extends keyof DB[T] ? DB[T][C] : never : never
  : SE extends AnyColumn<DB, TB> ? ExtractColumnType<DB, TB, SE>
  : never
```

## AnyColumn

`04-query-builders-orm/kysely/src/util/type-utils.ts`

A mapped type becomes a for-in loop.

**Original TypeScript** (4 lines)

```ts
export type AnyColumn<DB, TB extends keyof DB> = {
  [T in TB]: keyof DB[T]
}[TB] &
  string
```

**ScriptType** (7 lines)

```ts
export function AnyColumn(DB, TB: keyof typeof DB) {
  const out = emptyObject
  for (const T in keySet(TB)) {
    out[T] = keyof(DB[T])
  }
  return out[TB] & string
}
```

**Compiles back to**

```ts
export type AnyColumn<DB, TB extends keyof DB> = { [T in TB]: keyof DB[T] }[TB] & string
```

## DrainOuterGeneric

`04-query-builders-orm/kysely/src/util/type-utils.ts`

kysely's instantiation-depth trick, exposed as defer().

**Original TypeScript** (1 lines)

```ts
export type DrainOuterGeneric<T> = [T] extends [unknown] ? T : never
```

**ScriptType** (6 lines)

```ts
export function DrainOuterGeneric(T) {
  if (matches<[ unknown ]>([T])) {
    return T
  }
  return never
}
```

**Compiles back to**

```ts
export type DrainOuterGeneric<T> = [T] extends [unknown] ? T : never
```
